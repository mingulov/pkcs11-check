# Local Builds — Soft Token R&D

Local builds of PKCS#11 soft tokens for fast development and debugging.
Much faster than Docker rebuilds for iterative testing.

## Directory Structure

```
local-builds/
├── README.md           # This file
├── build.sh            # Build one or all tokens
├── test.sh             # Run p11test against a local build
├── kryoptic/           # Kryoptic source + build
│   └── .so             # → libkryoptic_pkcs11.so
├── softhsm2/           # SoftHSM2 source + build (latest from git)
│   └── .so             # → libsofthsm2.so
├── pkcs11-mock/        # pkcs11-mock source + build
│   └── .so             # → pkcs11-mock.so
├── bouncyhsm/          # BouncyHSM (needs .NET — optional)
└── tokens/             # Token data directories (gitignored)
    ├── kryoptic/
    ├── softhsm2/
    └── ...
```

## Quick Start

```bash
# Build a specific token
bash local-builds/build.sh kryoptic

# Build all supported tokens
bash local-builds/build.sh all

# Run tests against a local build
bash local-builds/test.sh kryoptic
bash local-builds/test.sh softhsm2-local   # uses the locally-built version
bash local-builds/test.sh softhsm2-system  # uses the Ubuntu package (2.6.1)

# Run specific tests against a local build
bash local-builds/test.sh kryoptic -k test_encrypt -v
```

## Tokens & Build Requirements

| Token | Language | Local Build | Notes |
|-------|----------|-------------|-------|
| **Kryoptic** | Rust | Yes | `cargo build --release` — needs rustc 1.70+ |
| **SoftHSM2** | C++ | Yes | autotools build — needs gcc, openssl-dev, sqlite3-dev |
| **pkcs11-mock** | C | Yes | cmake — minimal deps |
| **BouncyHSM** | .NET | Optional | needs `dotnet` SDK — skip if not installed |
| **OpenCryptoki** | C | No | needs pkcsslotd daemon, complex setup — use Docker |
| **NSS** | C | No | complex Mozilla build system — use Docker |

## How It Works

- `build.sh` clones (or updates) the source into `local-builds/<token>/src/`
- Builds the `.so` library into `local-builds/<token>/lib/`
- `test.sh` sets up a fresh token directory, initializes the token, and runs p11test
- Token data goes to `local-builds/tokens/<token>/` (gitignored)
- Each token has its own config file generated by `test.sh`
